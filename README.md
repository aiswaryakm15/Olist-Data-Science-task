# Olist Brazilian E-Commerce Data Analysis

## Project Overview

This project analyzes the Olist Brazilian E-Commerce dataset using SQL, Excel, Power Query, and statistical analysis to generate useful business insights.

## Tasks Completed

### Task 1 – RFM Customer Segmentation
Performed RFM analysis using Recency, Frequency, and Monetary values to segment customers into:
- Champions
- Loyal
- Potential Loyalists
- At Risk
- Lost

### Task 2 – Revenue Leakage Detection
Compared expected order value with payment value and identified orders with significant payment mismatches above the defined threshold.

### Task 3 – Funnel Conversion Analysis
Analyzed the e-commerce order funnel across:
- Orders Placed
- Orders Paid
- Orders Shipped
- Orders Delivered
- Orders Reviewed

### Task 4 – Cohort Retention Analysis
Created monthly customer cohorts based on first purchase and analyzed customer retention across subsequent months.

### Task 5 – Seller Profitability
Analyzed seller performance using:
- Revenue
- Profit
- Profit Margin
- Seller Ranking

### Task 6 – Excel Power Query & Data Model
Used Excel Power Query to:
- Import and clean Olist datasets
- Handle missing delivery dates
- Create Order Lifecycle Days
- Create Delivery Delay Days
- Build the Data Model / Star Schema

### Task 7 – Excel KPI Analysis
Calculated important e-commerce KPIs:
- Customer Lifetime Value (CLV)
- Average Order Value (AOV)
- Repeat Purchase Rate
- On-time Delivery %

### Task 8 – Statistical Analysis
Analyzed the relationship between delivery delay and customer review scores.

**Results:**
- Correlation: **-0.2611**
- Slope: **-0.03451**
- R²: **0.0682**

The results indicate a weak negative relationship between delivery delay and review score.

### Task 9 – Executive Summary
Combined the findings from all previous tasks and provided business insights and recommendations related to:
- Customer segmentation
- Revenue risks
- Customer retention
- Delivery performance
- Seller profitability
